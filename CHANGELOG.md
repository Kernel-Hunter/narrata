# Changelog

## 0.2.0 (3 November 2026)

- Pronunciations. Under More, Pronunciations, add a word and how to say it, spelled the way it sounds ("Siobhan" as "shiv awn", "nginx" as "engine x"). Select a word in the document first and it is filled in. Listen plays the spelling with the current voice. The list applies to every document and voice, to audio exports, and to the sentence being read as soon as you change it. Words match whole and ignore case, and a phrase of several words works too. The list is kept in the browser's local storage. The Chrome extension does not use it yet.

## 0.1.0 (31 October 2026)

- First release: the web app and the Chrome extension (as a zip to load unpacked).
- The web app tells open pages when a new version is deployed, and the extension popup says when a new release is out.
